# Downloads

Ready-to-use plugin jars for **Paper 26.2** on **Java 25**. Click a jar, then the download button
(the arrow at the top right of the file view), and put it in your server's `plugins` folder.

| Jar | What it is | Needs |
|---|---|---|
| UNBank-1.0.0.jar | Nations, treasuries, daily tax, UN treasury | EssentialsX + VaultUnlocked |
| UNBorders-1.0.0.jar | Nation land claims, raiding only during approved wars | UNBank |
| UNGraves-1.0.0.jar | Graves that keep your items safe (keepInventory off) | nothing |
| UNMenu-1.0.0.jar | Button menus for Bedrock players | Floodgate |
| UsefulTrades-1.2.2.jar | Extra villager trades, steady prices, x5 mob drops, anvil levels, money sidebar | nothing |
| worth.yml | Optional EssentialsX `/sell` price list (copy to `plugins/Essentials/worth.yml`) | EssentialsX |

These are the same jars that run on United Nations of MC With Gang.
